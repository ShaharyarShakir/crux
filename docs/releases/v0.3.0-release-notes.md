## Scope

Crux v0.3.0 introduces custom application build configuration, compiler sanitizer instrumentation, deterministic build fingerprinting, and rich terminal output diagnostics.

This release enables developers to declare compiler and linker flags directly in their `crux.toml` application manifests, enable AddressSanitizer and UndefinedBehaviorSanitizer with automated compiler capability probing, and enjoy an enhanced terminal UI with Unicode progress bars and 256-color support while maintaining full pipeline reproducibility.

---

## What's New in v0.3.0

### 1. `[build]` Manifest Configuration

Applications can now declare custom C compiler flags, C++ compiler flags, and linker flags in `crux.toml`:

```toml
[build]
c_flags = ["-Wall", "-Wextra", "-pedantic"]
cxx_flags = ["-Wall", "-Wextra", "-Wconversion"]
linker_flags = ["-Wl,--as-needed"]
```

- **Application-Only Scope**: Build flags are passed strictly to the local application project. They are never propagated to third-party dependencies, preserving upstream build isolation and single-version consistency.
- **Zero Shell Interpolation**: Flags are parsed as structured arrays and passed to CMake as individually quoted list elements (`-DCMAKE_C_FLAGS=...`, `-DCMAKE_CXX_FLAGS=...`, `-DCMAKE_EXE_LINKER_FLAGS=...`). No shell expansion or metacharacter interpretation occurs.
- **Ordered Preservation**: Flags are preserved in their exact declaration order.

### 2. Compiler Sanitizers (`[build.sanitizers]`)

Crux v0.3.0 adds first-class support for AddressSanitizer and UndefinedBehaviorSanitizer on GCC and Clang toolchains:

```toml
[build.sanitizers]
address = true
undefined = true
```

- **Compile and Link Instrumentation**: When enabled, Crux configures both compiler flags (`-fsanitize=address`, `-fsanitize=undefined`) and linker flags (`-fsanitize=address,undefined`).
- **Toolchain Probing**: Before compiling, Crux executes a small probe compile-and-link command with the detected toolchain to verify sanitizer support.
- **Structured Diagnostics**: If a requested sanitizer is unsupported by the active compiler or host platform, Crux fails with a clear, actionable diagnostic detailing the missing compiler feature rather than failing mid-build with opaque linker errors.

### 3. Application Build Fingerprinting & Cache Invalidation

Crux implements deterministic fingerprinting for application builds (`.crux/builds/app/<profile>/<fingerprint>/`):

- **Comprehensive Tracking**: The fingerprint incorporates:
  - Compiler identity and version.
  - Declared `c_flags`, `cxx_flags`, and `linker_flags` in order.
  - Active sanitizers.
  - Build profile (`debug` vs. `release`).
  - CMake generator and version.
  - Lockfile dependency graph hash.
- **Automatic Rebuild Invalidation**: If flags, sanitizers, or compiler toolchains change, Crux detects the fingerprint mismatch and discards the stale build directory, ensuring clean, reproducible compilation.

### 4. Rich Terminal Output & Color Diagnostics

The Crux terminal engine has been enhanced for interactive developer productivity:

- **Unicode Glyphs & Block Progress**: High-resolution terminal progress bars (`█`, `▓`, `░`) and status symbols (`✓`, `✖`, `ℹ`) are rendered when connected to capable UTF-8 terminals.
- **256-Color Palette**: Soft 256-color gray accents and contextual highlights improve readability in modern terminal emulators.
- **Plain ASCII Fallback**: If standard output or error is piped, redirected to a file, or running under `TERM=dumb`, Crux automatically disables ANSI escape sequences and falls back to clean, predictable ASCII output.
- **Configurable Modes**: Fully honors `--color always|auto|never` and `NO_COLOR` / `CLICOLOR_FORCE` environment standards.

## Upgrade Guide

Crux v0.3.0 is backward-compatible with existing `crux.toml` manifests and `crux.lock` lockfiles:

- Existing manifests without a `[build]` table continue to build with default compiler and toolchain settings.
- Lockfiles generated in v0.2.0 or v0.2.1 remain valid and byte-compatible.
- To update your global installer:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/ShaharyarShakir/crux/main/install/install.sh | bash
  ```
